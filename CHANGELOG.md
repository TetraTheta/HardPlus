# v3.1.0

- Updated 'Wither Skeleton Bow'.
  - Wither Skeletons selected by `spawn-chance` now switch weapons depending on whether their target is affected by HardPlus.
- Added 'Hard Water'.
  - Affected players can no longer negate high fall damage by landing in water.

# v3.0.0

- Added WorldGuard support, thanks to JustusJG.
  - WorldGuard flag names are almost the same as permission nodes.
  - Replace `.` with `-`, such as `hardplus.cold-damage` -> `hardplus-cold-damage`.
  - See the wiki for more information.
